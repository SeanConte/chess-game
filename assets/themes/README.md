# Theme assets

`stone-onyx/` contains only reusable texture / ornament assets used by the current clean theme:

- `dark-stone.webp` — page / large dark surfaces
- `black-stone.webp` — Black Bank and dark card surfaces
- `ivory-stone.webp` — White Bank and light card surfaces
- `board-light.webp`, `board-dark.webp` — board square materials
- `grain.webp` — subtle surface variation
- `blue-gem.svg` — small jewel accent

Do not add screenshots or broad UI plates here as backgrounds for live game regions. Any new art should be a reusable material, isolated ornament, icon, or border component that does not contain baked-in board state, pieces, clocks, labels, or move history.
